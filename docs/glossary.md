# Glossary

Terminology follows [PLAN](PLAN.md); legal wording, dates and applicability require the review recorded in [rules sources](rules-sources.md).

| Term                   | Meaning in this project                                                                                                                                                                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| LUT (RFD-11)           | Letter of Undertaking used for the export-without-payment-of-IGST path; record its financial-year validity.                                                                                                                                             |
| FIRA / e-FIRA          | Foreign Inward Remittance Advice, including the digital document used to evidence foreign receipts and match them to payments.                                                                                                                          |
| RBI purpose code       | A code describing the nature of a foreign receipt; recommendations come from a sourced table and require bank confirmation.                                                                                                                             |
| GSTR-1 Table 6A        | The export-invoice section Niryat plans to prepare for portal upload; the accepted offline format remains unverified.                                                                                                                                   |
| Export of services     | PLAN's five-condition checklist: supplier in India, recipient abroad, place of supply abroad, convertible-foreign-exchange receipt, and parties not merely establishments of one person. Verify statutory exceptions and wording before implementation. |
| RBI realisation period | The legally applicable time allowed for export proceeds to be received; the plan's reported period is disputed and must not be hard-coded.                                                                                                              |
| Advance tax            | Income-tax payments due during the year, estimated using sourced rules rather than model-generated rates or dates.                                                                                                                                      |
| Presumptive taxation   | An eligible taxpayer's simplified income calculation scheme; qualification, limits and current section references require review.                                                                                                                       |
| Credit note            | A document used to adjust a previously issued invoice, including relevant refund adjustments under verified GST rules.                                                                                                                                  |
| ASMT-10                | A GST scrutiny notice concerning discrepancies; notice assistance is a stretch feature.                                                                                                                                                                 |
| GSTIN                  | Goods and Services Tax Identification Number; sensitive profile data that needs encryption before persistence.                                                                                                                                          |
